# Rank / Context: precision data journal
The owner delegated the theme redesign and publication to existing Pages. Make official ranking methodology feel like an exacting comparison journal: white technical paper, navy ink, fine blue rules, index labels, a structured source directory and comparison sheets. No fabricated ranking values, relative-performance bars or decorative graphs that imply data.

Keep the three source records, search/category/reset, source URLs and every caveat. Give target, measurement, geography, observation period and publication/check dates a clear reading order. Detail pages use a dossier-style metadata header and numbered reading sections. The landing comparison cards become aligned comparison sheets with distinctive criterion/limit treatment. Noindex, relative URLs, scripts/data and the absence of live updates remain unchanged.

A leaderboard was rejected because actual rank data and reuse rights are absent. A generic card catalog was rejected because it hides the important semantic differences. This data-journal structure foregrounds method rather than rank while staying a static source guide.
